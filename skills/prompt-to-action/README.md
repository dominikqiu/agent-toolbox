# 使用说明

此包包含一个轻量执行编排 skill。它将自然语言请求补全为最小任务定义并执行，默认不展示改写 prompt、不请用户确认流程；复杂任务才保存简短交接。

## 安装与默认使用

将整个 `prompt-to-action` 文件夹放入目标 agent 支持的 skill 目录，或使用该产品提供的导入入口。不同产品的目录和激活规则不同；上传文件不保证自动生效。

对于支持 `.agents/skills` 的 Codex 工作区，可以放为：

```text
<项目>/.agents/skills/prompt-to-action/SKILL.md
```

若希望不必每次点名，在该 agent 确实会加载的持久指令中加入下面一段；例如项目已有的 AGENTS.md 中，保留原内容后追加。路径按安装位置调整：

```text
处理我的可执行任务时，默认使用 prompt-to-action skill
（.agents/skills/prompt-to-action/SKILL.md）。
根据已知上下文补齐目标、范围和完成证据后直接执行；
不要先展示优化后的 prompt 或让我确认流程。
简单任务直接完成，复杂任务才保存简短状态；
只有会改变结果或授权范围的关键缺口才提问。
纯问答或我要求只给方案时，按该请求的边界回答。
```

技能选择依赖宿主行为，持久指令能明确默认偏好，但不能替代宿主权限、后台运行或状态持久化能力。跨项目使用时，需要配置该产品支持的用户级指令/技能；项目级 AGENTS.md 只覆盖其适用目录。


## 日常输入

安装并设置默认指令后，直接说“修复这个报错”“分析这个库”“整理成一份报告”即可，不必填写任务表。
需要临时改变行为时，直接说“先别执行，只给方案”“只改写这段 prompt”或“这次请先和我确认关键选择”。

## 预期行为示例

| 请求 | 行为 |
| --- | --- |
| 修复当前项目的这个报错 | 读取必要上下文、定位、修复、相关验证，不先索要完整需求模板 |
| 把这段说明写得清楚一点 | 直接改写，不建状态文件、不展开工作流 |
| 调研两个方案，推荐一个 | 核对比较依据，说明假设，交付有证据的建议 |
| 把它部署上去，但目标环境无法确定 | 先完成独立的准备和检查，询问部署目标，未确认前不执行依赖步骤 |
| 继续上次的任务 | 查最小状态摘要与实际产物，核对后继续 |
| 只帮我优化 prompt | 仅返回优化后的 prompt，不执行其中任务 |

此包没有包含 DSH 运行时、调度器或数据库，也不保证减少任何固定比例的 token；它通过省略重复模板、限制状态摘要和按需读取控制开销。
